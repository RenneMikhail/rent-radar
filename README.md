# rent-radar

Мониторинг аренды (Барселона, побережье до Таррагоны, коридор Сабадель/Террасса): Idealista, Pisos.com, yaencontre, Fotocasa, Habitaclia.
Сканы идут из залогиненного браузера на вашем Mac (порталы блокируют серверы), результаты фильтруются по критериям (500-1000 €, с мебелью, длительная аренда, без «temporada»/«только студентам»).

В репозитории только код. Данные, телефоны и текст сообщения лежат локально (`.gitignore`).

## Состав
- `scan/*.js` скрипты сканирования порталов, `monitor.py` ingest/build, `enrich/`, `geo.py`, `pack.py`, `screen.py` фильтры, `page_template.html` страница.
- `message.example.txt` шаблон сообщения арендодателю (`{addr}`, `{price}`, `{link}`).

## Планы
1. Постоянный фоновый запуск на Mac (launchd, раз в 2-3 минуты) + разбор почтовых уведомлений порталов.
2. Автоответ через контактную форму портала с дневным лимитом и режимом dry-run.
3. Кнопка «WhatsApp» (wa.me со вставленным текстом) для объявлений с телефоном.
